## 1. What I Learned in the Bootcamp So Far

The bootcamp has been a valuable learning journey that helped me move from basic programming awareness to a stronger understanding of how modern web applications are built. One of the most important concepts I learned is the backend architecture and the way client-server communication works in real systems. I now understand the role of HTTP, request and response cycles, APIs, and JSON as the foundation of web communication. I also gained a clearer perspective on RESTful design principles and how middleware sits between the client and the application to process requests, enforce rules, and improve maintainability.

From a JavaScript perspective, I strengthened my knowledge of the fundamentals that form the basis of good software development. This includes variables, primitive data types, scope, conditions, loops, functions, and arrays. I became more comfortable working with common JavaScript patterns and ES6+ features such as arrow functions, destructuring, spread/rest operators, and array methods like map, filter, reduce, and forEach. These concepts allowed me to write cleaner, more readable, and more efficient code, while also improving my problem-solving ability when dealing with data transformations and logic flows.

As the course progressed, I also explored more advanced JavaScript topics that are essential for real-world development. I learned how objects work, how to structure applications using object-oriented programming principles, how to work with timers and dates, and how to manage errors more professionally. I also gained practical exposure to regular expressions, promises, async/await, and the event loop, which gave me deeper insight into asynchronous behavior in JavaScript. Understanding how asynchronous code is executed helped me think more critically about performance, responsiveness, and application flow, especially in backend and API-related tasks.

TypeScript became another major milestone in my learning path. I developed a better understanding of static typing, type annotations, interfaces, and type aliases, and I now see how TypeScript improves code clarity, reduces bugs, and makes applications easier to maintain as they grow. The transition from JavaScript to TypeScript taught me the importance of writing safer and more predictable code, especially in larger systems where reliability matters.

I also learned the core building blocks of Node.js and the backend ecosystem. This includes working with built-in modules such as OS, FS, Path, and HTTP, understanding the difference between CommonJS and ES modules, and getting introduced to Express.js as a framework for creating web servers and APIs. This gave me a clearer understanding of how backend logic is structured and how server-side applications handle requests, route definitions, and responses.

In addition to technical concepts, I gained a strong foundation in Git and GitHub, which are essential in professional software development. I learned how to initialize repositories, track changes using git status and git add, create commits, work with remote origins, and manage branches effectively. I also became familiar with collaboration practices, version control workflows, branching strategies, and the value of maintaining clean project history. This is especially important because modern development is not only about writing code, but also about working efficiently and safely as part of a team.

Overall, this bootcamp has given me a strong combination of theory and practice. It has improved my technical understanding, sharpened my logical thinking, and made me more confident in my ability to build backend-oriented solutions. The most important takeaway is that I am no longer only learning syntax; I am learning how to think like a developer, structure my code, solve real problems, and collaborate effectively in a professional environment.
